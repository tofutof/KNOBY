# 🖼️ Case Study Assets Folder

Place your images here so the PDF Prompter can automatically embed them into the final Case Study PDF:

1. **`circuit_diagram.png`**:
   - Screenshot of your Wokwi / Tinkercad circuit simulation, breadboard schematic, or wiring diagram.
2. **`finished_project_1.jpg`** (or `.png`):
   - Photo of the completed physical Desk Buddy with the 9V battery and active OLED screen.

> **Tip:** You can name files anything you want—just update the file paths in `case_study_data.json` or type the image file path when prompted by `prompter.py`.
